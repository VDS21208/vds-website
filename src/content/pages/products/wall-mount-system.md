## What it is

The fixed-install counterpart to our Mobile Surveillance Unit. Same camera stack, same VMS, same SOC playbook — bolted to a building or pole instead of a trailer.

For sites where the perimeter is permanent and the value is in continuous coverage rather than rapid redeployment.

## What's in the system

- **PTZ camera** — HD with 25x optical zoom, pan/tilt/rotation. One operator can sweep an entire lot or building face.
- **3 or 4 fixed high-resolution cameras** providing 180° of overlapping coverage.
- **Optional license plate reader cameras** for vehicle entry/exit logging and watchlist alerts.
- **Live deterrence** — high-visibility police-style strobe lights and a 120 dB speaker for remote voice announcements.
- **Cellular connectivity** as a primary or backup link — installs faster than wired and survives ISP outages.
- **Onboard storage** for recorded footage with cloud sync to AI VisionStream.
- **Remote live view and playback** from any browser, phone, or tablet — plus optional 24/7 SOC monitoring.

## Where it fits

- **Permanent buildings** — warehouses, distribution centers, manufacturing facilities, fleet yards.
- **Multi-tenant commercial** properties needing a single operator-monitored perimeter.
- **Critical infrastructure** sites with hard mounting points available.
- **Auto dealerships** with multi-acre lots and existing pole structures.

## How it pairs with the rest of the stack

- Same **AI VisionStream** cloud VMS used by the trailer fleet — one operator dashboard for mixed deployments.
- Same **24/7 SOC** playbook — live audio challenge, dispatch with live video, 97% false-alarm filtering.
- Same **AI analytics** library — LPR, loitering, object detection, crowd management, smoke and fire detection.
- Same **NDAA Section 889** compliance documentation.

If you run both trailers and wall mounts on a portfolio of sites, you run them from one operator console with one SLA.
