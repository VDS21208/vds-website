## What it does

Manage users, sites, cameras, and permissions across multi-tenant hierarchies — integrators, dealers, sub-accounts, end customers.

## Key capabilities

### Multi-tenant hierarchies
Integrators, dealers, sub-accounts, end customers. Granular delegated admin.

### Role-based access
Custom roles per user type — operator, supervisor, customer, law enforcement, first responder.

### Bulk camera onboarding
Add 100+ cameras with CSV import. Auto-provision common configs.

### Remote configuration
Push settings to any camera. Schedule recordings. Update firmware remotely.


## How it fits with VDS

VDS deploys **solar-autonomous mobile surveillance trailers** that come pre-integrated with AI VisionStream — including Admin Portal. The same feature works on your existing IP cameras (any ONVIF/RTSP, no NDAA-prohibited brands) and across drones, body cams, and IoT devices.

## Compliance & security

- AWS US-only · TLS 1.3 · AES-256
- NDAA Section 889 compliant
- SOC 2 documented
- GDPR / CCPA / PIPEDA aware
- Configurable retention
